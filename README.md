# Proyecto Final - Portfolio Personal (CoderHouse)

Este proyecto fue desarrollado como entrega final del curso de Desarrollo Web de CoderHouse. Su objetivo principal fue diseñar y desarrollar una página web de portfolio personal para presentar mis proyectos, habilidades y ofrecer métodos de contacto a potenciales clientes o empleadores.

🚀 Tecnologías Utilizadas

HTML5

CSS3

JavaScript

Bootstrap

📌 Descripción

Portfolio Personal - Proyecto Final
El sitio web fue diseñado para servir como una herramienta de presentación personal, permitiéndome mostrar mi perfil profesional, mis proyectos y facilitar la comunicación con interesados en mis servicios.

📌 Objetivo del Proyecto

Presentar mi perfil y habilidades de manera profesional.

Mostrar los proyectos realizados durante el curso y otros adicionales.

Incluir secciones que permitan conocerme mejor tanto a nivel personal como profesional.

Ofrecer métodos de contacto directos y accesibles.

🛠️ Características

✅ Diseño moderno y atractivo.
✅ Secciones: Presentación, Sobre mí, Proyectos, Habilidades, Contacto.
✅ Portafolio con proyectos destacados.
✅ Información de contacto y redes sociales.
✅ Diseño responsive adaptado a distintos dispositivos.

🚀 Lo que aprendí

🔹 Organización y estructuración de un sitio completo desde cero.
🔹 Aplicación de buenas prácticas de diseño y desarrollo web.
🔹 Desarrollo de un portfolio funcional que comunica efectivamente mi perfil profesional.
🔹 Implementación de diseño adaptable y optimización de la experiencia de usuario.
